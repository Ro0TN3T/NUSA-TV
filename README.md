# NUSA TV • Android TV Native (Kotlin)

Aplikasi streaming TV Nasional Indonesia & Katalog Siaran Langsung untuk **Android TV Box** berbasis **Kotlin + Media3 ExoPlayer**.

## Aset Visual Sudah Lengkap di Dalam Proyek
- `icon-nusa-tv.png` & `app/src/main/res/mipmap-*/ic_launcher.png`: Ikon APK resmi bertuliskan **NUSA TV** dengan tema dark-navy & cyan.
- `app/src/main/res/drawable/app_banner.png`: Banner widescreen untuk tampilan Launcher Android TV Box.
- `app/src/main/res/drawable/nusa_tv_logo.png`: Logo untuk Loading Screen (`SplashActivity`) dan Header aplikasi.

## Cara Build APK Otomatis di GitHub (Tanpa Laptop/PC)
1. Ekstrak file ZIP ini di HP Anda.
2. Buat repository baru di GitHub melalui browser HP.
3. Upload seluruh isi folder hasil ekstrak (termasuk folder `.github/workflows/build-apk.yml`) ke repository tersebut.
4. Buka tab **Actions** di repository GitHub Anda, tunggu proses **Build Android TV APK** selesai.
5. Unduh file **NusaTV-AndroidTV-APK** di bagian **Artifacts**.
